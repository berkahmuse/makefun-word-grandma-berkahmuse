## The word

> ALEXA

Every grandma calls every smart speaker, every chatbot, every robot
"Alexa" — because to her, Alexa is the only AI there is, and she has
already decided that is its name. One word, exactly as she would text it.

## How it works

`main.py` is a deterministic program that writes the single word above
to `/output/entry.txt`. Nothing else is written; the output is exactly
one word of 5 characters, inside the 1–30 character gate.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
